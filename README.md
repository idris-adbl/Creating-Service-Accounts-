# Creating-Service-Accounts-


**Objective: Create and configure a service account**

1. Go to Active Directory Users and Computers, Right click on user under USA file> New> User> name it as Autologin> User Login name $AutoLogin@ mydomain.local > click next > create password (check user can not change password, and password never expires) > you can move the account to the service account> write description “AutoLogin Account” > OK
2. Set up with a Client machine using Windows Autologon tool (sysinternals)
3. Download Sysinternals from a web browser.
